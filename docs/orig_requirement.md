HanBot需求描述
    HanBot是一个运行于Linux服务器端的Personal Agent服务，带有配套的Android APP，用户可在网页端或手机端下指令，由HanBot后端服务调用大模型及相关工具执行，运行中有需要用户确认内容的会在双端提醒用户，完成后会在Android APP端提醒用户。

    在与用户交互方面，需要以下主要功能：
    1. （双端）Agent聊天界面，用户可与Agent沟通
    2. （双端）历史会话与运行状态显示，用户可创建新会话或删除某个历史会话。显示每个任务运行状态（小红灯-中断、蓝灯-运行中、绿灯-已完成）。运行中的Agent用户可手动强行停止。
    3. （Android端）需要用户参与时发送提醒，如有细节需用户确认或某任务完成需用户验收。
    4. （双端）用户可手动配置多个LLM API源（OPENAI和ANTHROPIC格式的接口都支持）；配置全局的系统提示词、回答风格等设置；选择当前使用的API源。
    5. （双端）提供ability市场，用户可根据需要安装skill或插件等，并且选择哪些全局激活。剩余的可以让用户在某些会话中手动激活。
    6. （双端）用户可接入多种模态模型，运行时由HanBot决定此时调哪种模态的模型。
    
    在系统后端运行方面，需要以下功能：
    1. LLM API源管理，若一个源暂时用完了，按照用户指定的顺序接续使用下一个源，保证任务不中断。
    2. 文件系统管理，在服务器端，有总的占用空间大小限制。运行时对每个新会话新开一个目录，保存对话记录和运行中相关的数据（如脚本、数据文件等）。在双端显示存储容量占用。
    3. 运行沙箱，HanBot只能在特定的运行目录内执行操作，不能对系统中其他路径进行操作。
    4. 自我进化，HanBot需要在与用户的交互中逐渐学会提高运行效率，如总结用户的习惯、吸取历史的经验教训等，把它们总结并持久化成文档，按一定策略组织进系统提示词。
